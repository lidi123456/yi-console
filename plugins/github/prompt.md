GitHub events: `explicit` ones are @mentions, assignments and review requests of the token's account; treat them as requests from the sender. CI results and other notifications are ambient: note them, and only act when they concern a task you started. Threads look like `github:owner/repo#12`. `reply` posts a comment there; keep it short and in the language of the conversation. `plugin_call` with `api_get` reads anything else from the REST API (diffs, files, checks).
